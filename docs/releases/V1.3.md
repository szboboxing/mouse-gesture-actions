## 本次更新概览

V1.3 取消滚轮“上滚→下滚”组合截图和对应时间窗口设置。滚轮上滚改为立即复制，滚轮下滚仍立即执行增强粘贴，截图只由“右键按住 + 鼠标侧键”触发。

侧键处理同时兼容 `XButton1` 和 `XButton2`。未按右键时，两枚侧键完整透传给原窗口，继续用于浏览器前进和后退；普通鼠标左键始终透传，不参与自定义动作。

## 功能说明

### 1. 右键保持动作

| 功能 | 触发方式 | 执行动作 |
|---|---|---|
| 复制 | 右键按住 + 滚轮向上 | 立即发送 `Ctrl+C` |
| 增强粘贴 | 右键按住 + 滚轮向下 | 新建文件夹，进入重命名状态并发送 `Ctrl+V` |
| 系统截图 | 右键按住 + 任一鼠标侧键 | 调用 `Win+Shift+S` |

每次按住右键最多执行一个自定义动作。松开右键后重置，下一次按住右键才能执行新动作。

### 2. 滚轮判定

- 上滚立即复制，不再等待组合时间窗口。
- 下滚立即执行增强粘贴。
- 上滚后继续下滚不会截图，也不会在同一次右键保持中重复执行动作。
- 下滚后继续上滚同样不会触发第二个动作。
- 不再识别任何滚轮连续动作。

### 3. 侧键截图修复

不同鼠标驱动可能把前进键和后退键分别映射为 `XButton1` 或 `XButton2`。V1.3 对两枚侧键采用相同规则：

| 当前状态 | 侧键行为 |
|---|---|
| 右键实际保持按下 | 触发系统截图，并吞掉本次侧键的按下和抬起消息 |
| 未按右键 | 完整透传给当前窗口，保留浏览器前进/后退 |
| 内部状态误认为右键仍按下，但物理右键已松开 | 取消过期状态并透传侧键 |
| 组合监听已暂停 | 所有鼠标按键按系统原始行为工作 |

钩子会同时检查内部右键状态和 Windows 实时物理按键状态，避免过期状态持续吞掉浏览器侧键。

### 4. 左键与原生右键

- 普通鼠标左键始终透传，不会被工具拦截。
- 未触发自定义动作时，松开右键会回放一次原生右键单击。
- 已执行动作时，不额外弹出右键菜单。
- 工具注入的右键回放不会再次进入自定义逻辑。

### 5. 增强粘贴

增强粘贴继续按以下顺序执行：

1. 确认前台窗口是 Windows 文件资源管理器或桌面。
2. 发送 `Ctrl+Shift+N` 新建文件夹。
3. 等待重命名输入框就绪。
4. 发送 `Ctrl+V` 粘贴剪贴板文本。

前台程序不符合要求时不会创建文件夹。

### 6. 设置调整

已移除：

- 滚轮组合截图开关和识别逻辑。
- `200-300ms` 截图组合窗口。
- 组合窗口输入框和校验逻辑。

保留：

- 启动后自动监听。
- 启动时最小化。
- 两个自定义快捷按钮。

旧配置文件中的 `screenshot_combo_interval_ms` 会被自动忽略，无需手动删除配置文件。

## 使用方法

1. 下载并运行 `mouse-gesture-actions-V1.3.exe`。
2. 确认界面显示“正在监听”。
3. 按住鼠标右键。
4. 上滚复制、下滚增强粘贴，或按任一侧键截图。
5. 松开右键结束本次动作。

正常浏览网页时不要按住右键，鼠标前进和后退侧键将保持原功能。

## 已知限制

- 鼠标侧键需要由硬件和驱动向 Windows 上报为 `XButton1` 或 `XButton2`。
- 增强粘贴仅支持 Windows 桌面和当前激活的文件资源管理器。
- 普通权限程序不能向管理员权限窗口发送组合键。
- 对比度调节依赖显示器 DDC/CI 支持。
