## 键盘映射扩展

两组自定义键盘映射现在支持：

- 修饰键：`Ctrl`、`Alt`、`Shift`、`Win`，可以任意组合，也可以全部不选。
- 主键：`A-Z`、`F1-F12`。
- 鼠标侧键：`X2 / 下一页`、`X1 / 上一页`。

例如可以配置：

```text
X2 / 下一页 → Win+E
X1 / 上一页 → Ctrl+Alt+F12
X2 / 下一页 → F5
```

按键执行时，修饰键按界面顺序按下，主键最后按下；释放时使用相反顺序，避免修饰键残留。`F1-F12` 使用 Windows 标准虚拟键码发送。

## 兼容性

- V1.8 及更早版本保存的字母快捷键配置可直接继续使用。
- 默认映射仍为 `X2 → Ctrl+C`、`X1 → Ctrl+V`，并保持初始关闭。
- 鼠标测试页和“右键保持 + 侧键截图”继续优先于普通键盘映射。
- Windows 保留快捷键仍由系统处理，例如 `Win+E` 会打开文件资源管理器。
