# 鼠标手势动作小工具 V1.2 版本说明

## 版本信息

| 项目 | 内容 |
|---|---|
| 版本 | `V1.2` |
| 发布日期 | 2026-08-08 |
| 支持系统 | Windows 10 / Windows 11 |
| 发布形式 | Windows 单文件 EXE，无需安装 Python |
| 方案 | 方案 A：右键保持组合 |

## 本次更新概览

V1.2 移除轨迹绘制识别，改为更直接的“按住右键 + 滚轮或侧键”组合。复制、增强粘贴和系统截图均只在右键保持按下期间生效；松开右键后立即退出组合状态。未触发任何组合的普通右键单击会回放给 Windows，保留原生右键菜单。

## 功能说明

### 1. 右键保持组合

| 功能 | 触发方式 | 执行动作 |
|---|---|---|
| 复制 | 右键按住 + 滚轮向上 | 向当前窗口发送 `Ctrl+C`，复制选中的文本或文件 |
| 增强粘贴 | 右键按住 + 滚轮向下 | 在当前目录新建文件夹，进入重命名状态并发送 `Ctrl+V` |
| 侧键截图 | 右键按住 + `XButton1` | 调用 Windows 截图工具 `Win+Shift+S` |
| 滚轮组合截图 | 右键按住 + 上滚后快速下滚 | 在设定时间窗口内调用 `Win+Shift+S` |

每次按住右键最多执行一个自定义动作。动作已提交后，继续滚动或按侧键不会在同一次右键保持中重复执行，松开右键后才会重置。

### 2. 滚轮事件判定

滚轮事件严格按顺序和时间判定：

| 事件顺序 | 判定结果 |
|---|---|
| 单次上滚 | 等待组合窗口结束后执行复制 |
| 上滚后立即松开右键 | 不再等待，直接执行复制 |
| 单次下滚 | 立即执行增强粘贴 |
| 上滚后在窗口内下滚 | 执行系统截图，不执行复制或增强粘贴 |
| 下滚后上滚 | 仅执行先发生的增强粘贴，不判定为截图 |
| 上滚后超过窗口再下滚 | 提交先发生的复制，不判定为截图或增强粘贴 |

这种延迟判定避免先执行复制、随后又把同一组滚轮事件识别为截图。

### 3. 截图组合窗口

- 可配置范围：`200-300ms`。
- 默认值：`250ms`。
- 数值越低，越不容易因滚轮抖动误触截图，但有意执行组合时需要更快。
- 数值越高，组合更容易触发，但刻度松散的滚轮更可能把抖动识别为“上滚→下滚”。
- 旧版配置会自动迁移，首次使用 V1.2 时采用默认 `250ms`。

### 4. 增强粘贴

增强粘贴按以下顺序执行：

1. 确认当前前台窗口是 Windows 文件资源管理器或桌面。
2. 发送 `Ctrl+Shift+N` 新建文件夹。
3. 等待重命名输入框就绪。
4. 发送 `Ctrl+V`，将剪贴板文本粘贴为文件夹名称。

当前前台程序不是资源管理器或桌面时，动作会被拒绝，不会在错误位置创建文件夹。剪贴板内容须能作为文件夹名称使用；Windows 不允许的字符仍受系统规则限制。

### 5. 系统截图

V1.2 提供两种截图入口：

- 右键按住 + `XButton1`，立即截图。
- 右键按住 + 上滚→下滚，在组合窗口内截图。

两种方式都固定发送：

```text
Win+Shift+S
```

截图组合触发时会吞掉对应滚轮或侧键事件，避免同时滚动页面或执行浏览器前进操作。

### 6. 原生右键行为

- 未触发任何组合时，松开右键会回放一次原生右键单击。
- 已执行自定义动作时，不再额外弹出右键菜单。
- 暂停组合监听后，右键、滚轮和侧键全部按系统原始行为工作。
- 工具自身注入的右键回放不会重复计入右键统计。

### 7. 移除的旧功能

V1.2 移除以下旧轨迹和独立动作：

- 逆时针、顺时针圆圈识别。
- 对勾截图识别。
- 同方向双快划新建目录。
- 删除动作。
- 回车确认动作。
- 自定义复制、粘贴、截图快捷键。
- 轨迹灵敏度和双划间隔设置。

增强粘贴仍包含“新建文件夹”步骤，但不再提供旧版独立的新建目录手势。

### 8. 保留的界面工具

V1.1 增加的以下功能继续保留：

- 左键、右键次数和鼠标移动距离统计。
- 各功能成功使用次数统计。
- 计算器、浏览器和媒体播放器快捷启动。
- 屏幕亮度与对比度调节。
- 两个可编辑自定义按钮。
- 随机鼓励语和统计清零。

## 使用方法

1. 下载并运行 `mouse-gesture-actions-V1.2.exe`。
2. 确认界面状态为“正在监听”。
3. 按住鼠标右键不放。
4. 滚轮上滚、下滚，或按 `XButton1` 执行动作。
5. 松开右键，退出本次组合状态。

Windows 会阻止普通权限程序向管理员权限窗口发送按键。如果目标程序以管理员身份运行，需要同时以管理员身份运行本工具。

## 已知限制

- 滚轮组合依赖硬件上报顺序，刻度松散或存在抖动的鼠标更容易误触；可将窗口调低至 `200ms`。
- `XButton1` 仅适用于带“向前翻页”侧键且由 Windows 识别为 `XButton1` 的鼠标。
- 增强粘贴仅支持 Windows 桌面和当前激活的文件资源管理器窗口。
- 增强粘贴依赖资源管理器重命名输入框及时获得焦点，系统负载较高时可能失败。
- 普通权限程序不能向管理员权限窗口发送组合键。
- 鼠标移动距离按屏幕像素累计，不代表物理长度。
- 对比度调节依赖显示器 DDC/CI 支持。
