## 关闭确认窗口

点击主窗口右上角关闭按钮后，软件不再直接退出，而是弹出三个按钮：

- `确认关闭`：执行完整退出流程，解除系统钩子并结束程序。
- `最小化`：关闭确认窗并最小化主窗口，全局监听继续运行。
- `取消`：关闭确认窗，保持主窗口和程序状态不变。

## 默认安全操作

- 确认窗弹出后，键盘焦点默认位于“取消”按钮。
- 系统鼠标指针自动移动到“取消”按钮中央。
- 按 `Enter` 执行取消。
- 按 `Esc` 执行取消。
- 点击确认窗右上角关闭按钮同样执行取消。
- 重复点击主窗口关闭按钮时只保留一个确认窗。

## 退出兼容性

“确认关闭”继续调用原有退出流程：

```text
解除系统钩子
→ 发送 WM_QUIT
→ 等待钩子与动作线程
→ 销毁 Tk 窗口
→ 释放 Mutex
→ 结束 GUI 子进程
```

原有 6 秒退出看门狗和进程残留保护保持不变。
