## 本次更新概览

V1.5 将“鼠标按键测试”从单纯检测扩展为侧键配置入口。用户可以确认上一页、下一页侧键是否被 Windows 识别，并把本轮实际检测到的侧键保存为截图触发键。

保存后立即生效。返回功能首页，按住右键再按已确认侧键，即可调用系统截图 `Win+Shift+S`。

## 侧键确认与保存

测试页新增“侧键截图确认”区域：

- 显示当前已保存的截图侧键。
- “重新确认侧键”会清空本轮侧键检测结果。
- 按下侧键后，鼠标图形、检测次数和确认提示同步更新。
- “保存检测结果”把本轮检测正常的侧键写入设置。
- 可只保存一枚可用侧键，也可保存两枚。
- 保存完成后立即更新全局鼠标钩子，无需重启程序。

## 使用方法

1. 在左侧进入“鼠标按键测试”。
2. 单击“重新确认侧键”。
3. 依次按下鼠标的上一页、下一页侧键。
4. 确认对应图形高亮，且计数增加。
5. 单击“保存检测结果”。
6. 返回功能首页。
7. 按住右键，再按已确认侧键测试系统截图。

如果只有一枚侧键能够被检测，可直接保存该侧键，该侧键即可用于截图。

## 判定结果

| 测试现象 | 结论 | 处理方式 |
|---|---|---|
| 图形高亮且计数增加 | Windows 已上报侧键信号 | 保存检测结果 |
| 仅一枚侧键有响应 | 一枚侧键可用 | 保存可用侧键，或检查另一枚 |
| 两枚侧键均无响应 | 未收到 `XButton` 信号 | 检查硬件和鼠标驱动映射 |
| 已保存但截图未弹出 | 可能存在权限或组合操作问题 | 确认按住右键，并检查程序权限 |

## 驱动边界

侧键截图依赖 Windows 低级鼠标消息：

```text
XButton1
XButton2
```

如果按下物理侧键时测试图形完全没有响应，说明程序没有收到鼠标侧键信号。此时需要在鼠标厂商驱动中将侧键恢复为“浏览器上一页/下一页”或 `XButton1/XButton2`，再回到程序重新确认。

软件可以保存并启用已经收到的侧键信号，但无法替代故障硬件或驱动凭空生成缺失的输入事件。

## 配置兼容

设置文件继续保存在：

```text
%APPDATA%\MouseGestureActions\settings.json
```

新增字段：

```json
{
  "screenshot_side_buttons": [
    "xbutton1",
    "xbutton2"
  ]
}
```

- V1.0-V1.4 的旧配置可直接读取。
- 旧配置默认启用两枚侧键，保持原有行为。
- 配置中的未知侧键值会被忽略。
- 无效或空配置自动回退为两枚侧键，避免升级后截图失效。

## 输入透传规则

- 测试页仍为只读测试模式，不执行复制、增强粘贴或截图。
- 未按右键时，上一页和下一页侧键继续完整透传给 Windows。
- 按住右键时，只有已确认保存的侧键会触发并吞掉截图组合。
- 未确认侧键保持系统透传。
- 每次右键保持仍然最多执行一个组合动作。

## 已知限制

- 侧键必须由硬件和驱动向 Windows 上报为 `XButton1` 或 `XButton2`。
- 驱动若把侧键映射为键盘快捷键，需先恢复为浏览器前进/后退侧键。
- 普通权限程序不能向管理员权限窗口发送截图快捷键。
