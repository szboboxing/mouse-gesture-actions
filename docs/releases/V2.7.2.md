# 鼠标手势动作小工具 V2.7.2 版本说明

本版本做四件事：轮盘的「风格」按效果图重做为 **奶油风 / 极简冷淡风 / 苹果风**，并升级为立体图标与悬停回弹动画；修复高分屏上 **「风格」按钮被挤出窗口** 的问题；把「更多设置」之后的 **控制面板整套界面统一重绘为奶油风**，与轮盘的暖色底对齐；最后对打包体积做一轮 **精简**。动作逻辑与手势判定不变，仍是内网离线单文件程序。

## 轮盘外观：奶油 / 冷淡 / 苹果，默认奶油风

- 「◍ 风格」按钮按 奶油 → 冷淡 → 苹果 循环，图标随风格变化（◍ / □ / ◈），文字始终显示当前风格名；默认外观为 **奶油风 + 明亮**，V2.7.0 的冰霜 / 烟晶 / 彩璃 三种风格与贴图一并下线。
- 每种风格都有明亮、暗夜两版，共 6 张 640×400 PNG 随程序打包（193,318 字节，原 522,314 字节），切换即时生效、无需等待。
- 风格不只换颜色，也换 **形状**：圆角半径、描边粗细、投影深浅、是否有高光线、标签是否加胶囊底、悬停是否带外圈光晕，全部由 `themes.geometry()` 按风格给出。奶油是大圆角实心卡片 + 柔和投影 + 顶部高光线，冷淡是直角细描边、无投影无高光、标签为裸文字，苹果是 iOS 圆角卡片 + 彩色描边与系统色图标。
- 奶油与苹果风格的 9 个图标（8 个磁贴 + 中心 ⚙）改为 **立体渲染**：顶部高光、底部反光、暗色描边、三段渐变外加一层偏移投影；「⊕」与计算器按键采用镂空画法，让卡片底色透上来。图标由开发期 Pillow 脚本离线渲染成索引色 PNG（`assets/icons/<风格>/<明暗>/<图标>_<尺寸>.png`），运行时只用 `tk.PhotoImage` 读取，**EXE 不打包 Pillow**；9 图标 × 4 尺寸（26 / 34 / 40 / 46）× 2 风格 × 2 明暗共 144 张、223,418 字节。冷淡风格保持扁平文字图标，不占用任何素材。
- 鼠标悬停改为 **阻尼弹簧动画**（ζ≈0.56）：磁贴放大 14%、上浮 4 像素、投影加深、外圈高亮环外扩，松手过冲一次后回弹落位；每帧只重绘动了的那一两块磁贴所以不闪烁，命中判定始终按静止位置计算，不会追着指针跑或在边缘抖动。
- 「＋／－」小按钮上的文字按底色自动选深浅（`themes.readable_text_on`），浅色块上不再出现白字看不清；「增强粘贴」磁贴改用深色图标（奶油 #A85638、苹果 #0071E3）或白卡墨框（冷淡），并新增亮度差 > 0.25 的强制校验。

## 轮盘顶栏：「风格」按钮不再被挡住

- **现象**：150% 缩放的机器上，顶栏最右侧的「◍ 风格 · 奶油」药丸会被窗口边缘切掉，点不到。
- **真实原因是 DPI，不是间距**：程序启动时调用 `SetProcessDpiAwareness(2)`，Tk 的 `tk scaling` 随系统 DPI 变成 2.0，于是所有 **磅值字号** 放大 1.5 倍；而轮盘窗口（640×660）、壁纸（640×400 PNG）与 144 张立体图标都是 **固定像素**，一点不放大。实测最长状态文案（已开启 · 正在监听 + 增强模式徽标）下顶栏需要 **835px**，最短文案也要 767px，而窗口只有 640px——被挤出去的正好是 pack 在最后的「风格」。开发机以 DPI 无关方式跑脚本时只需要 661px，所以此前一直没被复现。
- **修法一：字号按像素钉死**。新增 `themes.wheel_font(磅值)`，把按 96 DPI 设计出来的磅值换算成 Tk 的负数（像素）字号，轮盘与剪贴板历史条的 14 处字号全部改用它。这样文字和贴图在同一坐标系里，顶栏在 96 / 144 / 192 DPI 下实测都是 **610px**，与开发期截图所见一致。
- **修法二：让状态文字而不是按钮让步**。`pack` 的顺序就是空间分配顺序，原先左侧状态区排在最前、永远占满自己要的宽度，挤压全落在最后 pack 的「风格」上。现在右侧按钮组先 pack、状态区最后 pack 并加 `anchor="w"`，万一空间真的不够，被裁掉的只是状态文字末尾，四枚按钮始终完整可点。
- **修法三：收紧间距 + 抬高窗口下限**。状态区左边距 20→13、状态点间距 10→7、药丸内边距 14→11 与间距 8→6、徽标内边距 14→10 与间距 12→9、「更多设置」内边距 18→14 与右边距 20→14，最长文案下顶栏需求由 661px 降到 610px；轮盘窗口的 `minsize` 宽度由 600 提到 **620**，即使用户手动拖小，610px 的顶栏也放得下。
- **为什么不改成「窗口随 DPI 放大」**：那需要把 6 张壁纸与 144 张图标一并放大（Tk 的 `PhotoImage` 只能整数倍 zoom/subsample，1.5× 要走 zoom(3)+subsample(2)，单张瞬时内存约 9MB），改动面与风险都远大于把字号钉成像素。控制面板是真正可自由缩放的大窗口，仍保持磅值字号，跟随系统 DPI。

## 控制面板统一为奶油风

- 控制面板的配色不再是写死在 `app.py` 里的 17 个冷蓝灰常量，而是整表取自 `themes.panel_palette()`——36 个奶油风令牌（侧边栏、页面、卡片、文字、描边、主强调、成功/警告/危险、输入框、选中态、禁用态、鼠标示意图）。轮盘磁贴与控制面板卡片读同一张表，改一处即可，不会再出现「轮盘是暖色、设置页是冷蓝灰」的割裂。
- 覆盖到的每一处：左侧导航栏（浓缩咖啡深棕 + 奶油白文字 + 焦糖链接）、功能首页的三张手势卡、触发记录、鼠标统计器、自定义键盘映射区、快捷工具条、AI 工具输入框、启动设置、鼠标按键测试页的鼠标图示与检测结果、Toast 提示、关闭方式对话框。
- ttk 控件（组合框、复选框）此前由 clam 主题自带冷灰底，现在 `fieldbackground` / `bordercolor` / `arrowcolor` / `indicatorcolor` 全部吃奶油令牌，聚焦态用焦糖棕描边、选中态用奶油高亮。
- 帮助窗口原本抄了一份独立的冷蓝灰配色，现在同样读 `themes.panel_palette()`，与控制面板共用一处定义。
- 控制面板固定使用奶油风浅色，不随轮盘的「风格 / 明暗」切换；帮助说明里「外观只影响轮盘」一条已改写为说明这一层关系。

## 按 WCAG 校准过的对比度

- 次要文字 `muted` 由 #8A7668 加深到 #776254：页面底 4.8、卡片底 5.65，达到 AA。
- 承载白字的状态色全部提到 4.5 以上：成功 #487851（5.03）、警告 #A5651D（4.58）、危险 #B4453A（5.33）、主强调 #A85638（5.06）。
- 卡片描边 `line` 由 #E7D2B9 加深到 #D9BFA2，暖白卡才真正浮在奶油页面上；禁用态文字同步加深一档。
- 鼠标按键测试的示意图整体加深一档（`diagram` #EEDCC4、`diagram_soft` #DFC9AF、`diagram_line` #C9A98C、`diagram_strong` #A37F5F），滚轮上的「按下」二字改用正文色，改版前浅底上几乎看不见轮廓的问题解决。

## 修正的问题

- **「保存设置」会重置其他配置**：原先这里是重新构造一个 `AppSettings` 并逐个字段传值，凡是没列进去的字段都会被悄悄写回默认值——点一次「保存设置」，轮盘风格 / 明暗回到「奶油 + 明亮」，剪贴板历史开关回到开启，AI 工具路径被清空。现改用 `dataclasses.replace`，只覆盖面板上真正的三个开关加键盘映射，其余字段原样保留；今后 `AppSettings` 新增属性也不会再复发。
- 帮助窗口底部「关闭」按钮的 `accent` 参数此前没有生效，所有按钮一个颜色；现在它用更深的焦糖棕，与首页 / 上一页一排区分。

## 配置兼容

- `wheel_style` / `wheel_mode` 仍写入 `%APPDATA%\MouseGestureActions\settings.json`，下次启动自动恢复。
- 旧配置里的 `frost` / `graphite` / `pastel` 属于本版退役的取值，加载时自动回落为 `cream`，无需手动清理；其它非法值同样回落为「奶油 + 明亮」。

## 打包体积精简

- 相对上一个发布版本 V2.7.0 的本地构建（9,468,668 字节），本版单文件 EXE 为 **8,188,589 字节**，减少 1,280,079 字节（约 −1.22MB）；其中美术素材替换（壁纸 522,314 → 193,318 字节）与下面这一轮依赖与运行时裁剪各占一半左右，裁剪这一轮本身把 9,274,431 降到 8,188,589（−1,085,842）。
- **浏览器磁贴不再走 `webbrowser` 模块**：它在 Windows 上最终也是调用 `os.startfile`（`GenericBrowser` 分支还会牵连子进程栈），现在直接 `os.startfile("about:blank")`，行为等价。整条 `webbrowser` / `subprocess` / `signal` / `selectors` / `shlex` 依赖链下线。
- **排除只在 CPython 自测函数里出现的 `statistics`**：唯一引用点是 `random._test_generator()`（永远不会被调用），它又牵连 `decimal` / `fractions` / `_pydecimal` 与 `_decimal.pyd`，合计约 0.2MB。
- **排除压缩后端**：`shutil` / `zipfile` 对 `lzma` / `bz2` / `tarfile` / `gzip` 都是 try/except 的可选导入，本程序不解压任何归档，`_lzma.pyd`(88,565) 与 `_bz2.pyd`(45,269) 随之消失。
- **排除 `importlib.metadata` 及其 `email` / `csv`**：程序里没有任何调用点，少一整套 SMTP/HTTP 报文解析库也更符合内网无外联的要求。
- **裁剪 Tcl/Tk 运行时数据（615 个文件）**：`tzdata`（609 个时区文件，Tcl 在 Windows 上读注册表时区，不查 zoneinfo）、`http1.0` 与 `http` 包（不做任何 HTTP 请求）、`tcltest` 与 `platform`（只被 Tcl 自检框架使用）。必须保留的 `msgcat`（`clock.tcl` 与 `tk.tcl` 都 require）、`opt0.4`、`encoding/`（中文 Windows 的 cp936）、`msgs/`（本地化按钮文案）逐项核对后留在包里。
- 结果：`PYZ.pyz` 1,670,880 → 1,270,969 字节，`_tcl_data` 877,559 → 548,381 字节，`tcl8` 73,868 → 10,037 字节。
- **刻意没有动的部分**：`win32com`（增强粘贴与亮度控制都要靠 COM 分支，约 155KB，留着更稳）、40 像素图标档（悬停放大的亮度/对比度磁贴实际会取到这一档，删了会掉回扁平字形）。
- 顺带清掉两处死代码：`actions.py` 里未使用的 `import sys`、`app.py` 里未使用的 `RadialMenuItemSettings` 导入。

## 安全

- 全程不联网、不外发任何数据，适用于内网环境；本版还顺手去掉了 Tcl 的 `http` 包与 Python 的 `email` 报文解析库，可外联的代码面更小。
- 壁纸与立体图标都是随 EXE 打包的本地 PNG，由 `tk.PhotoImage` 直接读取，不引入任何图像库依赖（Pillow 只在开发期渲染，不打进包）；所有颜色、图标、壁纸仍是随 EXE 打包的本地资源，不引入任何运行时依赖。
- 构建为单文件 EXE，可在 Windows 10 / Windows 11 直接运行。
