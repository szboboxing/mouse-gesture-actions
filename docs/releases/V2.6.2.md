# 鼠标手势动作小工具 V2.6.2 版本说明

本版本按使用反馈优化轮盘主界面的尺寸与交互，功能逻辑不变，仍是内网离线单文件程序。

## 轮盘主窗口缩小约三分之一

- 轮盘主窗口由 960×960 调整为 640×660，启动后不再占满屏幕；窗口仍可自由拉伸，「更多设置」控制面板保持原有大小。
- 磁贴标签外移到 1.14 倍半径，窗口缩小后标签不再压住磁贴描边。

## 亮度、对比度图标分成「加 / 减」两部分

- 亮度与对比度磁贴改为一分为二：上半仍是功能图标（☀ / ），下半左侧「＋」提高、右侧「－」降低，两半都用鼠标左键单击生效，悬停时对应半块加粗描边。
- 修复「只能增加、点减没有反应」：旧版依赖右键降低，而全局鼠标钩子会吞掉按下右键的消息（用于右键保持手势），右键并不总能送达轮盘画布，导致「减」经常失效；现在完全不依赖右键。
- 兼容保留：在磁贴上按右键仍然执行「降低」。
- 新增 `tests/test_radial_menu.py`（10 项）覆盖两半命中判定与方向派发。

## 「更多设置」文案

- 轮盘中心 ⚙ 下方新增小字说明「更多设置」。
- 右上角按钮文字由「⚙ 设置」改为「⚙ 更多设置」。

## 剪贴板历史按钮顺序

- 面板右侧「清空」与「More」互换排列位置：自左向右依次为「记录：已开启/已暂停」「More」「清空」。

## 帮助说明更新

- 设置页左侧「❓ 帮助说明」的「🧰 界面工具」模块新增「鼠标轮盘主界面」「剪贴板历史」两个条目，并更新「快捷启动与显示调节」的显示调节说明，与 V2.6.2 的实际交互一致。

## 安全

- 全部功能本地运行，不联网、不外发任何数据，适用于内网环境。
- 构建为单文件 EXE，可在 Windows 10 / Windows 11 直接运行。
