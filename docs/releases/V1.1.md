## 本次更新概览

V1.1 重点优化高 DPI 环境下的界面显示，并增加鼠标使用统计、系统快捷工具、显示器调节、自定义按钮和随机鼓励语。原有鼠标手势及普通右键单击行为保持不变。

## 功能说明

### 1. 界面显示优化

- 窗口尺寸根据当前屏幕分辨率动态调整，并设置合理的最小尺寸。
- 标题和功能说明支持自动换行，尽量完整显示文字内容。
- 扩大左侧设置区域，避免选项文字和输入框受到挤压。
- 将识别记录区域宽度缩小约一半，为鼠标统计器预留独立空间。
- 主区域调整为“手势功能、识别记录、鼠标统计”三栏布局。

### 2. 鼠标统计器

统计器记录本次程序运行期间的数据：

| 统计项 | 统计规则 |
|---|---|
| 左键次数 | 每次物理左键按下计数一次 |
| 右键次数 | 每次物理右键按下计数一次 |
| 移动距离 | 根据连续鼠标坐标累计像素距离 |
| 功能使用次数 | 仅在对应功能执行成功后增加 |

功能使用次数包括复制、粘贴、截图、新建文件夹、计算器、浏览器、媒体播放器、亮度调节、对比度调节和自定义功能。

- 暂停手势识别后，鼠标按键和移动距离仍会继续统计。
- 程序生成的右键回放事件不会重复计数。
- 统计数据仅在当前会话中保存，退出程序后不会写入配置文件。
- 单击“统计清零”可清除全部鼠标统计和功能使用次数。

### 3. 快捷工具区

界面下方提供 8 个视觉功能位：

| 功能位 | 操作 | 说明 |
|---|---|---|
| 计算器 | 单击 | 启动 Windows 计算器 |
| 浏览器 | 单击 | 使用系统默认浏览器打开 Bing |
| 媒体播放器 | 单击 | 优先启动 Windows 音乐应用，失败时尝试 Windows Media Player |
| 屏幕亮度 | 单击 `－` 或 `＋` | 每次降低或提高约 5% |
| 屏幕对比度 | 单击 `－` 或 `＋` | 每次降低或提高约 5% |
| 统计清零 | 单击 | 清除本次会话的全部统计数据 |
| 自定义 1 | 左键执行，右键编辑 | 启动用户配置的目标 |
| 自定义 2 | 左键执行，右键编辑 | 启动用户配置的目标 |

亮度和对比度各占一个功能位，功能位内部使用两个小按钮分别执行降低和提高操作。

### 4. 亮度与对比度调节

- 内置屏幕亮度优先通过 Windows WMI 调节。
- WMI 不可用时，亮度调节会尝试使用 DDC/CI。
- 外接显示器亮度和对比度调节依赖显示器支持并启用 DDC/CI。
- 显示器不支持相关接口时，程序会显示失败原因，不会改动其他系统设置。
- 多显示器和部分厂商显示器的支持情况取决于硬件、连接方式及驱动程序。

### 5. 自定义功能按钮

每个自定义按钮均可设置：

- 按钮名称，最多 12 个字符。
- 程序路径。
- 文件路径。
- 文件夹路径。
- `http://` 或 `https://` 网址。
- 包含 Windows 环境变量的路径。

操作方式：

1. 右键单击“自定义 1”或“自定义 2”打开编辑窗口。
2. 输入按钮名称和目标地址后保存。
3. 左键单击按钮执行已配置目标。
4. 未配置目标时左键单击按钮，也会直接打开编辑窗口。

配置保存在：

```text
%APPDATA%\MouseGestureActions\settings.json
```

### 6. 随机鼓励语

- 程序启动时在界面底部随机显示一句鼓励语。
- 单击“换一句”可立即切换内容。
- 鼓励语仅用于界面展示，不会联网获取或上传任何数据。

## 默认鼠标手势

| 手势 | 绘制方式 | 默认动作 |
|---|---|---|
| 左向圆圈 | 按住右键逆时针画圆 | `Ctrl+C` 复制 |
| 右向圆圈 | 按住右键顺时针画圆 | `Ctrl+V` 粘贴 |
| 对勾 | 按住右键先向右下，再向右上 | `Win+Shift+S` 截图 |
| 同向快划两次 | 快速向右上两次，或快速向左下两次 | 在当前资源管理器目录新建文件夹 |

普通右键单击仍保持 Windows 原有右键功能。双次快划必须方向相同，并在设定时间内完成。

## 使用方法

1. 下载并运行 `mouse-gesture-actions-V1.1.exe`。
2. 确认界面状态为“正在监听”。
3. 按住鼠标右键绘制完整轨迹。
4. 松开右键后执行识别到的动作。
5. 根据需要使用统计器、快捷工具或自定义功能按钮。

Windows 会阻止普通权限程序向管理员权限窗口发送按键。如果目标程序以管理员身份运行，需要同时以管理员身份运行本工具。

## 已知限制

- 鼠标移动距离以屏幕像素累计，不代表实际物理长度。
- 统计数据不会跨程序重启保存。
- 对比度调节不提供软件 Gamma 替代方案，硬件不支持 DDC/CI 时无法调节。
- 当前目录新建文件夹仅支持 Windows 桌面和当前激活的文件资源管理器窗口。
