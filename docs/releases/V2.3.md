# 鼠标手势动作小工具 V2.3 版本说明

## 版本信息

| 项目 | 内容 |
|---|---|
| 版本 | `V2.3` |
| 更新日期 | 2026-09-21 |
| 支持系统 | Windows 10 / Windows 11 |
| 发布形式 | Windows 单文件 EXE，无需安装 Python |
| 重点变更 | 映射 2 的“增强粘贴”升级为醒目的整行大按钮 |
| 发布范围 | 本地验收构建 |

## 界面变更

“自定义键盘映射键”栏目中，映射 2 的“增强粘贴”由原来的小号复选框改为整行大按钮：

- 字号由 8 号加大到 11 号加粗，按钮高度约为原复选框的两倍，并占满映射卡片整行宽度。
- 开启时按钮显示“增强粘贴：已开启”，使用绿色填充和白色文字。
- 关闭时按钮显示“增强粘贴：已关闭”，使用灰色填充和深色文字。
- 鼠标悬停时为手型指针，按下有加深的按压颜色反馈。
- 映射 1 的“增强粘贴”复选框保持原样，不做改动。

## 功能兼容性

- 本次仅调整界面，不改变任何功能逻辑。
- 大按钮仍绑定原有的增强粘贴开关变量，点击后立即保存配置并同步到鼠标监听。
- 保留“勾选增强粘贴不清空已选修饰键和主键、取消后恢复原快捷键”的规则。
- 保留同一侧键最多启动一组映射、后启动者生效并自动停用另一组的规则。
- 配置回滚、外部配置加载等场景下，大按钮颜色和文字会随开关状态自动刷新。
- 保留主窗口关闭确认、侧键截图、鼠标按键测试等其余全部功能。
- 本地 `dist` 继续自动保留版本号最高的两个 EXE。
