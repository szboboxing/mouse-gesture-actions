## 本次更新概览

V1.4 在左侧栏目新增“鼠标按键测试”模块。进入后会显示鼠标图形，操作实际鼠标时，对应按键区域实时高亮或变色，可用于检查物理按键、滚轮和侧键是否正常上报给 Windows。

测试页采用只读测试模式。测试期间所有鼠标输入继续透传给当前窗口，不会执行复制、增强粘贴或截图；离开测试页后自动恢复原组合监听状态。

## 功能说明

### 1. 左侧功能导航

左侧栏目现在包含两个页面：

| 页面 | 用途 |
|---|---|
| 功能首页 | 原有右键组合、统计、快捷工具和设置 |
| 鼠标按键测试 | 实时检查鼠标物理按键和滚轮输入 |

两个页面在同一个窗口内切换，无需打开额外窗口。

### 2. 支持检测的鼠标输入

| 检测项目 | Windows 输入 | 图示反馈 |
|---|---|---|
| 左键 | `WM_LBUTTONDOWN / UP` | 按下高亮，抬起恢复 |
| 右键 | `WM_RBUTTONDOWN / UP` | 按下高亮，抬起恢复 |
| 中键 / 滚轮按下 | `WM_MBUTTONDOWN / UP` | 滚轮区域高亮 |
| 滚轮向上 | 正滚轮 Delta | 向上箭头短暂变色 |
| 滚轮向下 | 负滚轮 Delta | 向下箭头短暂变色 |
| 上一页侧键 | `XButton1` | X1 区域高亮 |
| 下一页侧键 | `XButton2` | X2 区域高亮 |

滚轮没有独立抬起消息，因此滚轮方向采用约 `220ms` 的脉冲高亮。

### 3. 检测结果与计数

- 页面显示最后一次检测到的按键名称。
- 七类输入分别累计触发次数。
- 按键按下时，右侧状态指示点同步变色。
- “清空测试记录”可将所有测试次数和最后检测结果重置。
- 鼠标移动不计入按键测试次数，也不会触发图示变化。

### 4. 只读测试模式

进入鼠标按键测试页时：

- 暂停右键组合动作判定。
- 左键、右键、中键、滚轮和两枚侧键全部透传给 Windows。
- 不执行复制、增强粘贴或系统截图。
- 即使功能首页的组合监听原本处于暂停状态，测试事件仍可正常显示。
- 测试页中的组合监听按钮会临时禁用，避免状态含义混淆。

离开测试页时：

- 清除仍处于高亮状态的图形。
- 恢复进入测试页前的组合监听启用或暂停状态。
- 原有右键保持动作规则不变。

## 使用方法

1. 启动 `mouse-gesture-actions-V1.4.exe`。
2. 单击左侧“鼠标按键测试”。
3. 依次操作左键、右键、中键、滚轮向上、滚轮向下和两枚侧键。
4. 观察鼠标图形高亮、最后检测结果及独立计数。
5. 单击“功能首页”退出测试，恢复原组合监听。

测试右键时，系统原生右键菜单可能正常弹出，这是按键完整透传的预期行为。

## 原有功能兼容性

V1.4 保留 V1.3 的全部组合规则：

| 功能 | 触发方式 |
|---|---|
| 复制 | 右键按住 + 滚轮向上 |
| 增强粘贴 | 右键按住 + 滚轮向下 |
| 系统截图 | 右键按住 + `XButton1` 或 `XButton2` |

普通左键和未配合右键使用的侧键继续保持系统原生行为。

## 已知限制

- 鼠标侧键需要由硬件和驱动向 Windows 上报为 `XButton1` 或 `XButton2`。
- 某些鼠标驱动若把侧键重映射为键盘快捷键，程序无法将其识别为鼠标侧键。
- 测试页采用完整透传，右键菜单、页面滚动和浏览器前进后退可能同时发生。
- 普通权限程序不能向管理员权限窗口发送组合键。
