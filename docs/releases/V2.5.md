# 鼠标手势动作小工具 V2.5 版本说明

## 版本信息

| 项目 | 内容 |
|---|---|
| 版本 | `V2.5` |
| 更新日期 | 2026-10-05 |
| 支持系统 | Windows 10 / Windows 11 |
| 发布形式 | Windows 单文件 EXE，无需安装 Python |
| 重点变更 | 快捷工具栏目“自定义 1”升级为“鼠标指针大小”系统按钮 |
| 发布范围 | 本地验收构建 |

## 新增功能

“快捷工具”栏目第 6 列新增固定按钮“鼠标指针大小”，按当前系统版本自动分流：

- **Windows 11**：打开「设置 → 辅助功能 → 鼠标指针与触控」
  （`ms-settings:easeofaccess-mousepointer`）。
- **Windows 10**：打开「设置 → 轻松使用 → 调整鼠标和光标大小」
  （`ms-settings:easeofaccess-cursorandpointersize`）。

按钮带 🖱 图标和绿色配色，单击即调起对应系统设置页，无需再手动按图索骥。

## 自定义按钮调整

- 原“自定义 1”按钮升级为固定功能的“鼠标指针大小”系统按钮，不再支持右键编辑。
- 原“自定义 2”保留为唯一的“自定义”按钮（位于第 7 列），仍可右键编辑名称和打开目标（程序、文件、文件夹或网址）。
- 旧配置文件中已保存的“自定义 2”名称和目标会自动迁移到新的“自定义”按钮，无需重新配置；旧“自定义 1”字段被自动忽略。

## 功能兼容性

- 仅调整“快捷工具”栏目按钮，不改变任何手势识别、键盘映射、鼠标测试和设置保存逻辑。
- 设置文件结构升级为新字段 `custom_button_name` / `custom_button_target`，旧字段 `custom_button_1_*` 被忽略，`custom_button_2_*` 自动迁移。
- 本地 `dist` 继续自动保留版本号最高的两个 EXE。

## 验证范围

- 验证 Windows 11 单击“鼠标指针大小”跳转「辅助功能 → 鼠标指针与触控」。
- 验证 Windows 10 单击“鼠标指针大小”跳转「轻松使用 → 调整鼠标和光标大小」。
- 验证旧配置中的“自定义 2”数据正确迁移到新的“自定义”按钮。
- 验证“自定义”按钮右键编辑、保存、单击启动流程保持正常。
- 验证 V2.5 Windows 文件版本信息。
- 项目完整自动化测试全部通过。
- 启动正式 EXE 验证标题栏版本为 V2.5。
