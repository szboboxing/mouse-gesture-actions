## 本次更新概览

V1.6 修复部分鼠标的上一页、下一页侧键无法测试，以及侧键已经识别但“右键按住 + 侧键”无法调用截图的问题。

修复已使用实际主力鼠标验证。两枚侧键均可在测试页高亮和计数，也可在功能首页调用 Windows 截图 `Win+Shift+S`。

## 侧键测试修复

部分鼠标驱动会把侧键消息标记为注入输入。旧版统一过滤注入输入，导致测试页收不到这类鼠标的 `XButton1/XButton2`。

V1.6 调整为：

- 允许 `WM_XBUTTONDOWN / WM_XBUTTONUP` 进入侧键测试与截图判定。
- 其他注入型鼠标消息继续过滤，避免程序自身发送的输入形成循环。
- 测试页仍完整透传侧键，不影响浏览器上一页、下一页功能。
- 支持检测、确认并保存一枚或两枚可用侧键。

## 侧键截图修复

旧版为了延迟原生右键菜单，会先吞掉右键按下消息。此时 Windows 的异步右键状态可能不会更新，旧版再次查询该状态时会误判为“右键未按住”，因此取消截图动作。

V1.6 改为直接根据低级鼠标钩子收到的真实右键 DOWN/UP 维护保持状态：

- 收到右键 DOWN 后进入右键保持状态。
- 保持期间按下已保存侧键，立即执行截图。
- 收到右键 UP、关闭监听、切换测试页或更新侧键配置时清除状态。
- 未按右键时，两枚侧键继续完整透传给 Windows。
- 每次右键保持最多执行一个组合动作。

## 测试页图示调整

鼠标图形中的侧键位置已对调：

```text
上方：X2 / 下一页
下方：X1 / 上一页
```

事件名称、配置值和截图绑定保持不变，仅修正图形位置。

## 使用方法

1. 进入“鼠标按键测试”。
2. 单击“重新确认侧键”。
3. 依次按下上一页、下一页侧键，确认图形高亮且计数增加。
4. 单击“保存检测结果”。
5. 返回“功能首页”。
6. 按住右键，再按任意已保存侧键。
7. Windows 截图工具应立即弹出。
