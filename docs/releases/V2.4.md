# 鼠标手势动作小工具 V2.4 版本说明

| 项目 | 内容 |
|---|---|
| 版本 | `V2.4` |
| 更新日期 | 2026-09-26 |
| 支持系统 | Windows 10 / Windows 11 |
| 发布形式 | Windows 单文件 EXE，无需安装 Python |
| 重点变更 | 新增“❓ 帮助说明”帮助中心浏览窗口 |
| 发布范围 | 本地验收构建 |

## 新增功能

左侧功能导航在“功能首页 / 鼠标按键测试”下方新增“❓ 帮助说明”入口，单击打开统一的帮助中心窗口：

- 三级浏览结构：帮助中心首页（功能模块列表）→ 模块页（说明条目列表）→ 说明页（正文）。
- 覆盖五个模块：右键组合手势、自定义键盘映射、鼠标按键测试、界面工具、窗口与权限。
- 窗口底部提供“🏠 首页 / ⬆ 返回上级 / ◀ 上一页 / 下一页 ▶”四个导航按钮：
  - 首页：从任意页一键回到模块总览；
  - 返回上级：说明页 → 模块条目列表 → 首页；
  - 上一页 / 下一页：按模块顺序逐页翻阅，可跨模块，第一张和最后一张自动禁用；
- 窗口顶部显示“首页 / 模块 / 条目”面包屑，随时知道当前位置。
- 同一主窗口只保留一个帮助窗口，再次单击入口直接跳到首页并置顶，不会弹出多个窗口。
- 全部帮助文案均取自程序实际功能（手势判定规则、输入优先级、增强粘贴限制、侧键重新确认步骤、设置文件位置、关闭保护、权限限制等）。

## 功能兼容性

- 仅新增帮助入口与帮助窗口，不改变任何手势识别、键盘映射、鼠标测试和设置逻辑。
- 帮助窗口为非模态窗口，打开期间主程序的全局鼠标监听继续正常运行。
- 保留主窗口关闭确认、侧键截图、鼠标按键测试等其余全部功能。
- 本地 `dist` 继续自动保留版本号最高的两个 EXE。
