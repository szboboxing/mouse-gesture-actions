## 显示名称校正

V1.8 只调整显示层，不修改鼠标事件值和实际功能：

```text
内部 xbutton1 → 显示为 X2 / 下一页
内部 xbutton2 → 显示为 X1 / 上一页
```

以下位置已统一校正：

- 鼠标按键测试页的图示、检测结果及侧键状态。
- 首页侧键截图图标。
- 自定义键盘映射的下拉选项、预览、启动日志和触发记录。

默认键盘映射显示为：

```text
映射 1：X2 / 下一页 → Ctrl+C（初始关闭）
映射 2：X1 / 上一页 → Ctrl+V（初始关闭）
```

原有 `xbutton1`、`xbutton2` 配置值保持不变，因此 V1.7 及更早版本的用户设置可以直接继续使用。右键保持截图、普通侧键映射、测试页透传和浏览器原生前进后退行为均未改变。
