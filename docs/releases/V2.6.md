# 鼠标手势动作小工具 V2.6 版本说明

## 新增：轮盘主界面

启动程序后，主窗口即为鼠标轮盘界面：浅色磨砂背景、顶部状态栏显示监听状态，8 个功能磁贴围绕中心环形排列，采用"去底纹 + 细描边悬浮"的极简风格。单击磁贴即执行对应动作，中心 ⚙ 或右上角"设置"进入控制面板与全部设置。

- 轮盘是启动后的默认主界面，不再是覆盖在原窗口上的浮层。
- 顶部状态栏右侧新增"● 增强模式 / ● 普通模式"徽标，实时反映当前粘贴模式；对应磁贴也会高亮（增强＝红、普通＝橙）。
- 8 个默认操作：鼠标大小、普通粘贴、增强粘贴、对比度、AI 工具、亮度、浏览器、计算器。
- 亮度、对比度磁贴支持"左键加 / 右键减"，标签上以 ＋/－ 提示。
- 浏览器磁贴仅唤起系统默认浏览器，不强制访问任何外部站点；计算器、鼠标指针大小分别打开系统计算器与「设置 → 轻松使用 → 鼠标指针」页。
- AI 工具磁贴打开在设置页配置的程序，未配置时给出明确提示。

## 剪贴板历史

轮盘下方新增剪贴板历史面板，本地记录最近复制的文本，可随时启用或暂停：默认显示最近 5 条，点击 More 展开到 10 条，支持一键使用与清空。记录内容仅保存在本机配置目录，不联网、不外发。

## 设置页调整

- "返回轮盘"按钮更醒目（蓝色实心、加大字号与内边距、⟲ 图标）。
- 快捷工具区新增"AI 工具"输入框，可直接填写或"浏览…"选择程序路径并保存，与轮盘 AI 工具磁贴联动。
- 修复 Windows 10 下鼠标指针大小设置页打开错误的问题（统一使用 `ms-settings:easeofaccess-mousepointer`，实测 Win10 19045 与 Win11 均正确落地）。
- 旧版轮盘布局会在下次启动时自动升级为本版本的 8 个功能磁贴。

## 安全

- 全部功能本地运行，不联网、不外发任何数据，适用于内网环境。
- 构建为单文件 EXE，可在 Windows 10 / Windows 11 直接运行。
