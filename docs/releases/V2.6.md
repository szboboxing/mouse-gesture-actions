# V2.6 版本说明

## 新增：鼠标轮盘菜单

启动程序后自动弹出全屏半透明轮盘菜单，8 个快捷操作围绕中心环形排列，单击即可执行对应动作。

### 轮盘项目

| 位置 | 名称 | 动作 |
|---|---|---|
| 顶部 | 撤销 | Ctrl+Z |
| 右上 | 复制 | Ctrl+C |
| 右 | 粘贴 | Ctrl+V |
| 右下 | 新建表格 | 启动 Excel |
| 底部 | AI PPT | 待配置 |
| 左下 | 新建文字 | 启动 Word |
| 左 | 剪切 | Ctrl+X |
| 左上 | 打印 | Ctrl+P |

### 交互方式

- 鼠标悬停项目时显示蓝色高亮环。
- 单击项目：关闭轮盘并立即执行快捷键或启动应用。
- 单击中心 ×：关闭轮盘，程序继续在后台运行。
- 按 `Esc`：等同关闭轮盘。

### 设置

- 在"启动设置"面板新增"启动时显示轮盘"复选框。
- 轮盘项目配置保存在 `settings.json` 的 `radial_menu_items` 字段。
- 关闭该选项后启动不再弹出轮盘，仅保留原有主窗口。

### 技术实现

- 新增 `radial_menu.py` 模块：全屏 Toplevel + Canvas 绘制。
- 扇区命中检测基于角度和距离计算。
- 项目数据通过 `RadialMenuItemSettings` 持久化，支持后续自定义编辑。
