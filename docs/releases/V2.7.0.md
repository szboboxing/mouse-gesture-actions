# 鼠标手势动作小工具 V2.7.0 版本说明

本版本给轮盘主界面加上仿苹果玻璃质感背景，并提供「风格」与「明暗」两组外观切换；功能逻辑不变，仍是内网离线单文件程序。

## 轮盘玻璃背景壁纸

- 轮盘画布不再使用纯色底纹，改为铺一张仿苹果玻璃质感壁纸（毛玻璃、折射、高光），居中绘制，窗口变小时自动裁切、不拉伸变形。
- 内置 3 种风格：**冰霜**（冷白淡蓝浅色毛玻璃）、**烟晶**（银白到石墨的烟晶玻璃）、**彩璃**（蓝绿粉紫马卡龙彩玻璃）。
- 每种风格都有明亮、暗夜两版，共 6 张 PNG 随程序打包，切换即时生效、无需等待。
- 6 张贴图共 522,314 字节，单文件 EXE 因此由约 8.9MB 增加到 9,468,668 字节（约 9.0 MiB）。

## 顶部新增「风格」「明暗」两个按钮

- 「◈ 风格 · 冰霜」：单击按 冰霜 → 烟晶 → 彩璃 循环切换，按钮文字就是当前风格。
- 「☀ 明亮 / ☾ 暗夜」：单击在明亮模式与暗夜模式之间切换。
- 两个按钮互相独立：风格决定背景图，明暗决定整套配色，任意组合都可用。
- 选择立即写入 `%APPDATA%\MouseGestureActions\settings.json`，下次启动自动恢复；配置里的非法值会回落到「冰霜 + 明亮」。

## 暗夜模式的整体配色

- 磁贴、标签胶囊、中心 ⚙、亮度/对比度的「＋/－」小按钮、顶部状态栏、模式徽标与下方剪贴板历史条全部跟随明暗切换。
- 图标描边与文字在暗夜模式自动改用更亮的 iOS 深色变体（如 #4FA9FF、#FF453A、#30D158、#BF5AF2），保证在深色玻璃上依然清晰。
- 顶部栏与剪贴板面板的底色取自当前背景图自身的上/下边缘平均色，整窗看起来是同一块玻璃，不会出现拼接缝。
- 外观只作用于轮盘主界面，「更多设置」控制面板保持原有浅色布局。

## 磁贴改为实心玻璃卡片

- Tk 画布不支持半透明，磁贴底色由原来的「近乎透明的浅底」改为实心磨砂卡片（明亮＝近白，暗夜＝深蓝灰），配合细描边与投影，在有图案的背景上仍然好认好点。
- 悬停高亮改为双层描边（外圈对比色 + 内圈强调色），在任何背景上都能看清当前指向的磁贴。

## 窗口尺寸约束

- 轮盘主窗口的最大尺寸锁定为 640×660（最小仍为 600×600），确保背景图始终铺满画布、不出现纯色边带；进入「更多设置」控制面板后恢复自由缩放。

## 测试与文档

- 新增 `themes.py`（风格 / 明暗 / 调色板 / 素材定位）与 `tests/test_themes.py`（24 项）：覆盖风格与模式取值、循环与切换顺序、非法值回落、明暗两套调色板键一致、颜色格式、亮度对比、6 张贴图与边缘色齐备、贴图总体积上限。
- `tests/test_settings.py` 新增 3 项，覆盖轮盘外观默认值、持久化与非法值回落。
- 帮助说明「🧰 界面工具」新增「轮盘外观：风格与明暗」条目，并更新轮盘窗口尺寸说明。
- 单元测试合计 128 项全部通过。

## 安全

- 背景图是随 EXE 打包的本地 PNG，由 `tk.PhotoImage` 直接读取，不引入任何图像库依赖；不联网下载、不外发任何数据，适用于内网环境。
- 全部功能本地运行；构建为单文件 EXE，可在 Windows 10 / Windows 11 直接运行。
