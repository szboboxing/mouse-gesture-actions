# 鼠标手势动作小工具 V2.6.1 版本说明

本版本在 V2.6 轮盘主界面的基础上做体积与文案优化，功能不变。

## 体积优化

- 该工具为内网离线使用，不需要联网与 TLS，打包时排除 `ssl / _ssl / _hashlib / socket` 等模块，移除随之附带的 `libcrypto-3.dll`、`libssl-3.dll`；`hashlib` 走 CPython 内置 `_sha2`（`random` 的 sha512 仍可用），`socket / _socket` 未被任何功能使用。
- 桌面目录获取改用 `ctypes` 直接调用系统 `shell32.SHGetFolderPathW`，不再依赖 `win32com.shell`，从而排除 `win32ui` 及随之附带的 `mfc140u.dll`（约 5.6MB）。这不仅减小体积，还让未安装 VC++ 运行库的干净内网 Win10/11 机器也能直接运行。
- 单文件 EXE 由约 11.0MB 降至约 8.9MB。
- 未改动任何业务功能，94 项单元测试全部通过，冻结 EXE 实测可正常启动运行。

## 剪贴板历史文案

- 剪贴板历史面板启用状态按钮文案由「记录：开启」调整为「记录：已开启」，暂停态「记录：已暂停」及其余文字、配色、逻辑均保持不变。

## 安全

- 全部功能本地运行，不联网、不外发任何数据，适用于内网环境。
- 构建为单文件 EXE，可在 Windows 10 / Windows 11 直接运行。
