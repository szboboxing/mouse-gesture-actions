# 鼠标手势动作小工具 V2.7.1 版本说明

本版本重做轮盘的「风格」：按效果图交付的 **奶油风、极简冷淡风、苹果风** 三种外观替换 V2.7.0 的冰霜 / 烟晶 / 彩璃，并把默认风格改为奶油风；在此之上把轮盘图标升级为 **立体图标**，并为鼠标悬停加上 **放大浮起 + 回弹动画**。功能逻辑不变，仍是内网离线单文件程序。

## 风格换成奶油 / 冷淡 / 苹果，默认奶油风

- 「◍ 风格」按钮按 奶油 → 冷淡 → 苹果 循环，按钮图标随风格变化（◍ / □ / ◈），文字始终显示当前风格名。
- 默认外观为 **奶油风 + 明亮**；旧的 冰霜 / 烟晶 / 彩璃 三种风格与对应贴图已下线。
- 每种风格都有明亮、暗夜两版，共 6 张 PNG 随程序打包，切换即时生效、无需等待。
- 6 张贴图合计 193,318 字节，比 V2.7.0 的 522,314 字节小约 0.32MB，单文件 EXE 体积随之下降。

## 三种风格各自的长相

- **奶油风**：暖米色磨砂玻璃背景，大圆角实心卡片磁贴 + 柔和投影 + 顶部高光线，焦糖棕立体图标，标签是奶油药丸胶囊，激活磁贴整块染成浅杏色。
- **极简冷淡风**：近灰白背景，直角细描边磁贴、无投影、无高光，扁平文字图标统一墨蓝灰，标签为裸文字不加底，激活磁贴是白卡 + 墨色粗描边。
- **苹果风**：蓝绿粉紫马卡龙彩玻璃背景，iOS 圆角卡片 + 彩色描边，立体图标沿用 iOS 系统色（#0071E3 / #FF9500 / #FF3B30 / #30B0C7 / #AF52DE / #34C759 / #5E5CE6），标签胶囊，中心 ⚙ 为蓝色。
- 风格不只换颜色，也换 **形状**：圆角半径、描边粗细、投影深浅、是否有高光线、标签是否加胶囊底、悬停是否带外圈光晕，全部由 `themes.geometry()` 按风格给出。

## 立体图标（奶油 / 苹果）

- 奶油与苹果风格的 9 个轮盘图标改为 **立体渲染**：顶部高光、底部反光、暗色描边、随强调色变化的三段渐变，外加一层偏移投影，视觉上真正"凸"在卡片上。
- 覆盖鼠标大小、普通粘贴、增强粘贴、对比度、AI 工具、亮度、浏览器、计算器 8 个磁贴与中心 ⚙；亮度／对比度磁贴里的小图标同样立体。
- 「⊕」与计算器的按键采用 **镂空** 画法：图标自身留空，让卡片底色透上来，而不是画一块实心色块。
- 冷淡风格 **保持扁平文字图标**——发丝线、无投影正是这套风格的特征，它也因此不占用任何图标素材。
- 图标由开发期的 Pillow 脚本离线渲染成索引色 PNG（`assets/icons/<风格>/<明暗>/<图标>_<尺寸>.png`），运行时只用 `tk.PhotoImage` 读取，**EXE 不打包 Pillow**，与壁纸同一套做法。
- 9 个图标 × 4 个尺寸（26 / 34 / 40 / 46 像素）× 2 风格 × 2 明暗共 144 张，合计 223,418 字节；连同 6 张壁纸，随包美术素材约 0.41MB，仍小于 V2.7.0 单是壁纸的 522,314 字节。
- Tk 无法平滑缩放位图，所以磁贴按自身尺寸就近取一个尺寸档；卡片仍然连续缩放，图标换档读作"浮起"的一部分而不是拉伸。

## 鼠标悬停动画

- 指针移到磁贴上：磁贴放大 14%、上浮 4 像素、投影同步加深、外圈高亮环随之外扩；移开后回弹落回原位。
- 动画是 **阻尼弹簧积分**（ζ≈0.56）而非补间，所以松手时轻轻过冲一下再停住，观感比线性过渡自然；过冲有下限保护，磁贴不会沉到卡片下方。
- 每帧只重绘"动了"的那一两块磁贴（`canvas.delete("item_N")` 后局部重画），不做整盘清空重绘，因此动画期间不闪烁。
- 命中判定始终按 **静止位置** 计算：磁贴放大后不会"追着"指针跑，也不会在边缘来回抖动。
- 关闭面板或切换风格时会取消待执行的帧回调并清空弹簧状态，不会留下空转的定时器。

## 暗夜模式与配色

- 磁贴、标签、中心 ⚙、亮度/对比度的「＋/－」小按钮、顶部状态栏、模式徽标与下方剪贴板历史条全部跟随明暗切换。
- 顶部栏与剪贴板面板的底色取自当前背景图自身的上/下边缘平均色，整窗看起来是同一块玻璃，不会出现拼接缝。
- 「＋」小按钮上的文字改为按底色自动选深/浅（`themes.readable_text_on`），奶油与苹果风格的浅色「＋」块不再出现白字看不清的情况。
- 外观只作用于轮盘主界面，「更多设置」控制面板保持原有浅色布局。

## 修正的对比度问题

- V2.7.0 中「增强粘贴」磁贴是浅色底 + 白色图标，在奶油与苹果风格下图标与底色亮度差仅 0.15 左右，实际偏灰看不清。本版按效果图改为深色图标（奶油 #A85638、苹果 #0071E3）或白卡 + 墨色描边（冷淡），并新增亮度差 > 0.25 的强制校验。

## 配置兼容

- `wheel_style` / `wheel_mode` 仍写入 `%APPDATA%\MouseGestureActions\settings.json`，下次启动自动恢复。
- 旧配置里的 `frost` / `graphite` / `pastel` 属于已退役取值，加载时自动回落为 `cream`，无需手动清理；其它非法值同样回落为「奶油 + 明亮」。

## 安全

- 背景图与立体图标都是随 EXE 打包的本地 PNG，由 `tk.PhotoImage` 直接读取，不引入任何图像库依赖（Pillow 只在开发期渲染，不打进包）；不联网下载、不外发任何数据，适用于内网环境。
- 全部功能本地运行；构建为单文件 EXE，可在 Windows 10 / Windows 11 直接运行。
