## 增强粘贴映射

映射 1、映射 2 的 `A-Z / F1-F12` 选框后新增“增强粘贴”点选项：

- 未点选：侧键继续发送已配置的键盘组合。
- 已点选：侧键直接执行现有增强粘贴功能。
- 取消点选：立即恢复此前保存的修饰键和主键组合。
- 两组映射可分别设置，配置和启用状态立即保存。

增强粘贴会复用原有完整流程：

```text
确认当前窗口为文件资源管理器或桌面
→ 发送 Ctrl+Shift+N 新建文件夹
→ 等待进入重命名状态
→ 发送 Ctrl+V 粘贴剪贴板内容
```

非文件资源管理器或桌面环境会拒绝执行，避免在错误窗口发送按键。

## 界面调整

- 每张映射卡片的“启动/停用”按钮移动到标题行。
- 控制行按顺序显示侧键、Ctrl/Alt/Shift/Win、A-Z/F1-F12、增强粘贴。
- 预览文字会在键盘组合和“增强粘贴”之间即时切换。
- 增强粘贴成功后计入原有增强粘贴使用次数。

## 兼容性

- V1.9 及更早版本的键盘映射配置可直接读取。
- 旧配置没有功能类型字段时，默认保持普通快捷键模式。
- 默认映射仍为 `X2 → Ctrl+C`、`X1 → Ctrl+V`，并保持初始关闭。
- 测试页和“右键保持 + 侧键截图”继续优先于普通侧键映射。

## 验证范围

- 65 项自动化测试通过。
- 验证增强粘贴映射调用现有增强粘贴方法且不发送快捷键。
- 验证普通快捷键映射仍支持 Win、A-Z 和 F1-F12。
- 验证旧配置默认使用普通快捷键模式。
- 验证非法功能类型自动回退。
- 正式 EXE 启动和关闭后无残留进程。
