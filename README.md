# 鼠标手势动作小工具

[![CI](https://github.com/szboboxing/mouse-gesture-actions/actions/workflows/ci.yml/badge.svg)](https://github.com/szboboxing/mouse-gesture-actions/actions/workflows/ci.yml)
[![Latest Release](https://img.shields.io/github/v/release/szboboxing/mouse-gesture-actions?display_name=tag)](https://github.com/szboboxing/mouse-gesture-actions/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Windows 内网离线单文件工具（最新版 V2.7.2，约 7.8MB / 8,188,589 字节，全程不联网、不外发任何数据）。启动后主界面即为铺有风格壁纸的紧凑鼠标轮盘（640×660），可用顶部按钮切换 3 种风格（奶油 / 冷淡 / 苹果）与明亮 / 暗夜模式；按住鼠标右键时，滚轮和侧键可执行复制、增强粘贴及截图，普通侧键还可分别映射为自定义键盘快捷键；未启用映射的侧键保持浏览器前进、后退原生功能。

## 功能亮点

- **鼠标轮盘主界面**：环形 8 个功能磁贴（鼠标大小、普通粘贴、增强粘贴、对比度、AI 工具、亮度、浏览器、计算器）围绕中心悬浮排列，磁贴卡片样式随当前风格变化（圆角投影、直角细描边或彩色玻璃），悬停时磁贴放大浮起并回弹、单击执行；亮度与对比度磁贴分成「＋ / －」两半，左半提高、右半降低，都用左键单击；顶部状态栏显示”增强模式 / 普通模式”徽标，中心 ⚙ 与右上角按钮均标注”更多设置”。顶栏字号按像素固定，100% / 125% / 150% / 200% 缩放下布局完全一致，「风格」按钮不会被挤出窗口。
- **立体图标**：奶油与苹果风格的 8 个磁贴图标与中心 ⚙ 均为预渲染立体图（顶部高光、底部反光、暗色描边、偏移投影，颜色跟随各磁贴强调色），「⊕」与计算器按键采用镂空画法透出卡片底色；冷淡风格刻意保持扁平文字图标。图标是随包打包的本地 PNG，运行时只用 `tk.PhotoImage` 读取，EXE 不依赖任何图像库。
- **玻璃背景与明暗模式**：轮盘背景内置 3 种风格壁纸（奶油 / 冷淡 / 苹果），每种都有明亮、暗夜两版共 6 张本地 PNG；顶部「◍ 风格」按钮循环切换背景（图标随风格变为 ◍ / □ / ◈），「☀ 明亮 / ☾ 暗夜」按钮整套换色（磁贴、标签、状态栏、剪贴板历史一起变），选择即时保存、下次启动自动恢复。
- **右键手势**：按住右键 + 滚轮向上 = 复制，+ 滚轮向下 = 增强粘贴，+ 已确认侧键 = 调用 `Win+Shift+S` 截图；未触发动作时松开右键回放原生单击，不弹多余菜单。
- **侧键自定义快捷键**：两组 `X1 / X2` 可映射任意 `Ctrl / Alt / Shift / Win` + `A-Z / F1-F12` 组合，或映射为”增强粘贴”，独立”启动 / 停用”，配置即时保存。
- **本地剪贴板历史**：轮盘下方记录最近复制的文本（默认 5 条，More 展开 10 条），可随时切换”记录：已开启 / 已暂停”，右侧依次为 More、清空（清空在最右），纯本机存储。
- **显示与系统一键动作**：屏幕亮度、外接显示器对比度（DDC/CI）、鼠标指针大小设置页（Windows 11 / 10 自动分流）、计算器、默认浏览器、AI 工具等。
- **鼠标按键测试**：实时检测左 / 右 / 中键、滚轮方向与两枚侧键，可重新确认并保存实际可用的截图侧键。
- **三级帮助中心**：首页 → 模块页 → 说明页，支持跨模块逐页翻阅、面包屑与导航按钮，边界自动禁用。
- **奶油风控制面板**：「更多设置」之后的全部界面（导航栏、手势卡、触发记录、统计器、键盘映射、快捷工具、鼠标按键测试、帮助窗口）与轮盘共读 `themes.panel_palette()` 的 36 个奶油令牌，暖白卡片配浓缩咖啡色侧栏与焦糖棕强调色，文字对比度按 WCAG AA 校准。
- **单文件、离线、开箱即用**：下载 EXE 双击即运行，无需安装 Python；配置存于 `%APPDATA%\MouseGestureActions\`，旧版布局下次启动自动升级。

## 快速上手

1. 到下方任一平台的 Releases 下载 `mouse-gesture-actions-V2.7.2.exe`，双击运行（首次运行会安装全局鼠标钩子）。
2. 屏幕出现鼠标轮盘，单击磁贴执行对应动作；亮度、对比度磁贴点左半「＋」提高、点右半「－」降低；顶部「◍ 风格」切换外观背景、「☀ 明亮 / ☾ 暗夜」切换配色；单击中心 ⚙（下方标注”更多设置”）或右上角”⚙ 更多设置”进入控制面板。
3. 使用手势：按住鼠标右键——上滚复制、下滚增强粘贴、按已确认侧键截图。
4. 首次用侧键截图前，进入”鼠标按键测试”点”重新确认侧键 → 保存检测结果”。
5. 需要侧键发快捷键：在”自定义键盘映射键”选择侧键、修饰键与主键，点”启动”。
6. 关闭主窗口时可选”确认关闭 / 最小化 / 取消”；选择最小化后全局监听继续运行。

左侧”鼠标按键测试”模块可实时检测左键、右键、中键、滚轮方向及两枚侧键，并可重新确认、保存实际可用的截图侧键。

## 方案 A

| 功能 | 触发方式 | 动作 |
|---|---|---|
| 复制 | 右键按住 + 滚轮向上 | 立即发送 `Ctrl+C` |
| 增强粘贴 | 右键按住 + 滚轮向下 | 立即新建文件夹并粘贴剪贴板内容 |
| 侧键截图 | 右键按住 + 已确认保存的侧键 | 调用 `Win+Shift+S` |

每次按住右键最多执行一个动作。未触发动作时，松开右键会回放原生右键单击；已执行动作时不会额外弹出右键菜单。

## 判定规则

- 上滚立即复制，不再等待时间窗口。
- 下滚立即执行增强粘贴。
- 上滚→下滚不再识别为截图；同一次右键保持只执行先发生的动作。
- 右键按住时，已确认保存的 `XButton1` 或 `XButton2` 可立即截图。
- 未按右键时，已启动映射的侧键发送自定义快捷键并替代浏览器原生动作。
- 未启动映射的侧键完整透传给浏览器。
- 普通鼠标左键始终透传。

## 自定义键盘映射键

功能首页的“快捷工具”上方提供两组独立映射。每组均可选择：

- 鼠标侧键：`X2 / 下一页侧键` 或 `X1 / 上一页侧键`。
- 修饰键：`Ctrl`、`Alt`、`Shift`、`Win`，可任意组合，也可全部不选。
- 主键：`A-Z` 或 `F1-F12`。
- 功能：可点选“增强粘贴”，在当前目录新建文件夹、进入重命名状态并粘贴剪贴板内容。
- 状态：通过该组右侧的“启动/停用”按钮立即切换。

默认配置为：

```text
映射 1：X2 → Ctrl+C（初始关闭）
映射 2：X1 → Ctrl+V（初始关闭）
```

同一侧键最多启动一组映射；若两组选择相同侧键，后启动或后修改的一组生效，另一组自动停用。点选“增强粘贴”不会清空已选修饰键和主键，取消点选即可恢复原快捷键。配置和启用状态会立即保存。

输入优先级固定为：

```text
鼠标按键测试页透传
> 右键保持 + 已确认侧键截图
> 普通侧键键盘映射
> 浏览器原生前进/后退
```

启动任意键盘映射时会自动开启全局监听。手动暂停组合监听后，右键动作和键盘映射都会暂停。

## 关闭主窗口

点击主窗口右上角关闭按钮后，不会立即退出软件，而是显示三个选择：

- `确认关闭`：执行原有完整退出清理并结束程序。
- `最小化`：关闭确认窗并最小化主窗口，全局监听继续运行。
- `取消`：关闭确认窗并返回主窗口。

确认窗默认聚焦“取消”按钮，鼠标指针会自动移动到该按钮中央。按 `Enter`、`Esc` 或关闭确认窗本身也按取消处理。

## 增强粘贴

增强粘贴只在以下位置执行：

- 当前激活的 Windows 文件资源管理器窗口。
- Windows 桌面。

程序先发送 `Ctrl+Shift+N` 新建文件夹，等待重命名输入框出现，再发送 `Ctrl+V`。当前前台程序不是资源管理器或桌面时，动作会被拒绝，不会在错误位置创建文件夹。

剪贴板内容须能作为文件夹名称使用，Windows 禁止的文件名字符仍受系统规则限制。

## 鼠标按键测试

在左侧功能栏进入“鼠标按键测试”，可检测以下输入：

| 图示区域 | 检测内容 |
|---|---|
| 左键、右键 | 按下时高亮，抬起时恢复 |
| 中键 | 按下滚轮时高亮，松开时恢复 |
| 滚轮向上、滚轮向下 | 按滚动方向短暂闪烁 |
| `X2 / 下一页`、`X1 / 上一页` | 检测两枚鼠标侧键 |

测试页会显示最后检测结果，并分别累计七类输入的触发次数。测试期间进入只读模式，所有鼠标消息继续透传给 Windows，不会执行复制、增强粘贴或截图；离开测试页后恢复进入前的组合监听状态。

侧键无反应或截图失败时，可按以下步骤重新确认：

1. 单击“重新确认侧键”。
2. 按下可用的上一页、下一页侧键，图示和计数必须有响应。
3. 单击“保存检测结果”。
4. 返回功能首页，使用“右键按住 + 已确认侧键”调用截图。

可只保存一枚检测正常的侧键，也可保存两枚。保存后立即生效并写入设置文件，无需重启。若按侧键时图示完全没有响应，需要先在鼠标驱动中将侧键恢复为“浏览器上一页/下一页（`XButton1/XButton2`）”，软件无法替代硬件或驱动产生缺失的侧键信号。

## 界面工具

- 左侧功能导航：在功能首页、鼠标按键测试和帮助说明之间切换。
- 鼠标统计器：左键、右键次数、鼠标移动像素距离和各功能成功使用次数。
- 自定义键盘映射：两组 `X1/X2` 可独立选择键盘组合或增强粘贴。
- 轮盘外观切换：轮盘顶部「◍ 风格」在奶油 / 冷淡 / 苹果三种背景间循环（按钮图标随风格变为 ◍ / □ / ◈），「☀ 明亮 / ☾ 暗夜」切换整套配色，两者独立组合，切换即时生效并保存；奶油与苹果使用立体图标，冷淡保持扁平文字图标。指针悬停时磁贴放大浮起、投影加深，移开后弹簧回弹落位。
- 剪贴板历史：轮盘下方记录最近复制的文本，单击即可重新复制，默认 5 条，可展开到 10 条或暂停记录。
- 快捷启动：计算器、系统默认浏览器和 Windows 媒体播放器。
- 显示调节：亮度和对比度分别提供降低、提高按钮。
- 鼠标指针大小：一键打开系统鼠标指针大小设置页（按 Windows 11 / Windows 10 自动分流）。
- 自定义按钮：可右键编辑名称和打开目标。
- 随机鼓励语：启动时随机显示，也可单击“换一句”。
- 统计清零：清除本次运行的统计数据。
- GitHub 项目信息：左侧栏目底部显示项目名称和可点击的公开仓库地址。

内置屏幕亮度优先使用 Windows WMI；外接显示器亮度和对比度使用 DDC/CI。硬件不支持时会显示失败原因。

设置保存在：

```text
%APPDATA%\MouseGestureActions\settings.json
```

V1.0-V1.9 配置可继续读取；旧配置默认启用两枚截图侧键，并生成两组初始关闭的键盘映射。已移除的轨迹和组合窗口字段会被自动忽略。旧配置没有外观字段时按「奶油 + 明亮」显示，`wheel_style` / `wheel_mode` 取值非法（例如写入 `neon`，或 V2.7.0 的 `frost` / `graphite` / `pastel`）同样回落为默认组合。

## 已移除功能

当前版本不再使用轨迹绘制，并已移除：

- 逆时针、顺时针圆圈识别。
- 对勾截图识别。
- 同方向双快划新建目录。
- 删除和回车确认动作。
- 旧版轨迹灵敏度和双划间隔设置。
- 滚轮“上滚→下滚”组合截图。
- `200-300ms` 截图组合窗口及其界面设置。

增强粘贴仍包含“新建文件夹”步骤，但旧版独立新建目录手势已移除。

## 版本与发布

- 版本从 `V1.0` 开始按 `Vx.y` 递增。
- 唯一版本来源是 `version.py` 中的 `APP_VERSION`。
- Git 标签、版本文档和 GitHub Release 使用相同版本号。
- 每次构建后，本地 `dist` 自动保留版本号最高的两个 EXE。
- 更改本地版本保留数量或规则前，必须先征得用户确认。
- 本地使用中文文件名，GitHub Release 使用 `mouse-gesture-actions-Vx.y.exe`。
- Release 同时发布 `SHA256.txt`。

发布新版本：

1. 更新 `version.py`、功能、测试和 `docs/releases/Vx.y.md`。
2. 运行 `.\build.ps1`。
3. 提交代码并推送同名版本标签。
4. GitHub Actions 校验版本、测试、构建并创建 Release。

## 开发与测试

环境要求：

- Windows 10/11
- Python 3.11+

安装依赖：

```powershell
python -m pip install -r requirements-dev.txt
```

运行源码：

```powershell
python main.py
```

运行测试：

```powershell
python -m unittest discover -s tests -v
```

构建单文件 EXE：

```powershell
.\build.ps1
```

构建产物：

```text
dist\鼠标手势动作小工具_V2.7.2.exe
```

## 权限与限制

- 普通权限程序不能向管理员权限窗口发送按键，目标程序以管理员身份运行时，本工具也需要相同权限。
- 侧键需要鼠标硬件和驱动向 Windows 上报 `XButton1` 或 `XButton2`。
- 若鼠标驱动把侧键映射成键盘快捷键，需先在驱动中恢复为浏览器前进/后退侧键，再执行重新确认。
- 对比度调节依赖显示器 DDC/CI 支持。
